# 3D modelling and characters (Blender + Python, free tools)

**Version: v1 (2026-10-15).** Generalized from a character-likeness build (Ellie, TLOU2) in Blender 5.2
driven entirely by Python scripts, plus how professional character artists work.

**You may ask the user questions at any point**: the exact target (which version, age, look),
game-ready or high-fidelity, whether a download or new tool is OK, a big change of direction. Ask
early for references they have (a side view especially). The user prefers you never wait long for an
answer on small things: ask, proceed with the recommended option, say so.

## 1. The working agreement (every session)

1. **Only the final result counts.** Success = someone who knows the subject recognises it at once,
   from every angle, in every reference. Fit errors and converged maths are diagnosis tools, never
   proof; never show a result as good because the numbers are good.
2. **Be your own harshest critic before the user sees anything.** Put the model next to *all*
   references (not just the ones it already matches): "is this the character, or a similar person?"
   If not, keep working, or show it as work-in-progress with an honest list of what's wrong.
3. **More references beat more cleverness.** Front and side are the minimum, never the goal.
4. **Structure before cosmetics.** No brows, lashes, pores or freckles until the primary forms read
   right in grey clay.
5. **If a method loops, change the method.** 2–3 iterations without a visible gain → another tool,
   technique, or a restart of that part.
6. **It's a collaboration.** Ask when a decision is theirs; propose steps; no long silent runs.
7. **Docs current as you go** (progress, learnings, hand-off with the exact next action).
8. **Everything generated by a script** (`<project>/<name>_build.py`): never hand-edit a scene you can't
   regenerate. A live-reload watcher keeps the user's Blender window in step with the script.
9. **Free / open-source tools and assets only**, everything inside the project folder (venvs, caches,
   downloads); ask before anything outside it.

**Elon's algorithm here:** question each requirement (is "landmarks under 1 mm" needed for "that's
her"? no), delete steps that don't move the final look, simplify what's left, shorten the change →
judge-against-all-refs cycle (render only key views in parallel: ~45 s per change), automate last.

## 2. Pipeline with gates

| Stage | Output | Gate before moving on |
|---|---|---|
| 1 Brief | Exact target (character, version, age, look) | User confirms |
| 2 References | 20–60 refs, every angle, indexed (`refs/INDEX.md`) | Front, both 3/4, both profiles, high, low, back 3/4 |
| 3 Ref cameras | One Blender camera per key ref (photo as background, focal, pose) | Eyes, nose, mouth sit on the photo |
| 4 Primary forms | Bald grey clay head that reads as the subject | Recognition gate across all ref cameras, then the user |
| 5 Hair silhouette | Hair mass in grey | Silhouette matches in every ref camera |
| 6 Secondary forms | Lids, lips, folds, ears | Recognition gate again |
| 7 Surface | Skin, freckles, brows, lashes, eyes, hair strands | Side-by-side in matched light |
| 8 Body, outfit | Proportions, clothes | Full-body refs front and back |
| 9 Delivery | Game-ready (retopo, UVs, bakes, LODs, rig) or renders | Engine / render checks |

**If every reference shares a framing feature (hair around a face), test with it early in rough grey**:
a bald dome made the face read as someone else, and the hairstyle turned out to be the biggest miss.

## 3. References and cameras

- **One consistent source first** (same model, version, age); mixing versions gives a face that is no
  one. Other sources only to fill gaps, marked.
- **Lens:** telephoto (85–150 mm) refs are most reliable; match each ref's focal on its camera. View in
  perspective with the matched lens.
- **Raking light** shows plane changes (judge form); flat light only colour. Note expressions.
- **Read 3D structure off side/back refs** (hair ties, ears, skull), not fronts.
- Keep all ref cameras in the scene so the user can step through them (timeline markers per camera).
- How to gather: [`research` → web gathering](../research/references/web-gathering.md).

## 4. Primary forms: where likeness is won

- Bald, flat grey, one raking key light + weak fill (bright flat clay hides planes). Give clay eyes a
  dark iris, or they read as staring.
- Order: skull → jaw/chin mass → cheekbones/cheek fat → eye sockets → nose → mouth → ears. Big shapes
  first.
- **Region checklist at every gate** (one-line verdict per row; "not checked" when no view exists):

| Region | Views |
|---|---|
| Skull, forehead, temples | front, both 3/4, profile, back |
| Hairline + hair mass | all ref cams with grey hair, side/back |
| Brows / brow ridge | front, 3/4, profile |
| Eyes, lids | front, 3/4 zoomed |
| Nose (bridge, tip, lobule, alae) | front, 3/4, **profile measured per row** |
| Lips, mouth corners | profile measured, front, low 3/4 |
| Cheeks, mid-face | 3/4, low 3/4 |
| Chin, jaw line, jaw corner | front, 3/4, **low 3/4, under, straight below** |
| Under-chin → throat | **whole profile contour**, under view |
| Neck, ears | profile, back 3/4 |

- **No view = not checked.** If the user had to show you an angle (e.g. straight from below), add it
  to the loop permanently.
- **Judge each change on a zoomed A/B** (ref | before | after); a 2–3 mm change is invisible at
  contact-sheet scale. Then confirm on the full sheet.
- **Measure impressions before reshaping:** "eyes too big, mouth too small" were both false once
  measured (ratios from a landmark detector on ref and model in the same camera). What reads wrong in
  clay can be shading, not shape.
- **Measure blends, don't eyeball them** (per-row leftmost-skin pixel for a profile).
- Fresh-eyes checks: flip horizontally, thumbnail size, squint; swing the light.
- After each change, step through **all** ref cameras: a change that fixes one view and breaks another
  is wrong.
- Below ~1–2 mm, changes only show zoomed: when a pass's gains don't show at sheet scale, move to
  bigger shapes instead of more small brushes.

## 5. Methods toolbox (pick the fastest that works; switch when stuck)

| Method | Use | Notes |
|---|---|---|
| Base mesh + sliders (MPFB2 / MakeHuman, CC0) | Quick realistic start | Never build realistic humans from primitives (reads as clay) |
| Landmark warp (damped RBF) to measured points | Lock proportions across views | Exact RBF oscillates; damp it |
| Auto landmarks (MediaPipe Face Landmarker, 478 pts) | Objective comparison, camera solving | Fails on true profiles and backs |
| Per-ref camera solve (PnP) | Ref cameras automatically | Focal weakly constrained by a face |
| Code brushes (Gaussian displacement) + Taubin smoothing | Forms by eye, scripted | Gaussians add bumps; smoothing removes creases |
| Hair masks (MediaPipe segmenters) vs model masks | Fit the hair silhouette by measurement | Outline only; judge the interior separately |
| Photo-to-head tools (FaceBuilder, FLAME/MICA) | Strong starting head | Commercial / non-commercial licences: ask |
| Identity-similarity scoring | Extra signal at the gate | Never a substitute for eyes |
| Restart the part | When it fights every fix | Often faster than patching |

Techniques and parameters that worked: [likeness-techniques.md](references/likeness-techniques.md).

## 6. Anti-patterns (each cost real hours)

- Declaring success because landmark errors were small; fitting two views and calling it done.
- Tuning brows, lashes, freckles before the structure was right.
- Judging likeness from memory instead of next to the refs.
- Acting on old by-eye notes without re-checking them against the refs.
- Trusting a small posterior spread as truth (triangulated depth drifted 6–8 mm; check every 3D fit
  against the true profile).
- More parameter loops after a measured gap stopped moving: change the method.
- Long silent runs without docs or check-ins.
